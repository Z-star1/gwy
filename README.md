# GWY 公务员考试备考系统

**在职备考** · 每天 **2 小时** · **三个月**（90 天 / 180 小时）· 目标 **160 分**

## 备考节奏

| 阶段 | 时间 | 学时 | 重点 |
|------|------|------|------|
| 基础 | 第 1-4 周 | 48h | 系统学习各模块，建立知识框架 |
| 强化 | 第 5-8 周 | 56h | 分模块刷题，申论限时练小题 |
| 冲刺 | 第 9-12 周 | 76h | 每周全真模考，查漏补缺 |

## 工作日每日 2 小时

| 日期 | 行测 1h | 申论 1h |
|------|---------|---------|
| 周一 | 资料分析 20 题 | 归纳概括 1 道 |
| 周二 | 判断推理 30 题 | 精读评论 + 摘抄金句 |
| 周三 | 言语理解 30 题 | 综合分析 1 道 |
| 周四 | 资料分析限时训练 | 提出对策 1 道 |
| 周五 | 数量 10 题 + 常识 20 题 | 贯彻执行 + 错题回顾 |
| 周六 | 薄弱模块集中突破 | — |
| 周日 | — | 申论小题 + 大作文练习 |

## 功能

- **今日计划** — 根据星期几自动显示当天 2 小时学什么
- **进度追踪** — 学习时长 vs 180h 目标，模考成绩 vs 160 分
- **行测 / 申论** — 各模块备考技巧与状态管理
- **12 周周计划** — 每周主题和任务一目了然

## 快速开始

```bash
npm install
npm run dev
```

## 在职备考要诀

- **通勤碎片时间**：听时政、刷常识、回顾错题（额外 30 分钟）
- **午休 20 分钟**：看一篇评论或背成语
- **周末是主战场**：工作日保持手感，周末模考 + 写大作文
- **保证睡眠**：2 小时高效学习 > 4 小时低效熬夜

## 技术栈

React + TypeScript + Vite，数据保存在浏览器 localStorage。
