# GWY 公务员考试备考系统

目标 **160 分**（行测 85 + 申论 75），覆盖国考/省考双科备考。

## 功能

- **总览仪表盘** — 目标进度、模考成绩、学习时长统计
- **行测模块** — 常识、言语、数量、判断、资料，含备考技巧
- **申论模块** — 归纳概括、综合分析、对策、贯彻执行、大作文
- **模考记录** — 追踪每次模考成绩，对比 160 分目标
- **备考规划** — 12 周三阶段学习计划 + 160 分拆解策略

## 快速开始

```bash
npm install
npm run dev
```

浏览器打开 http://localhost:5173

## 构建部署

```bash
npm run build
npm run preview
```

构建产物在 `dist/` 目录，可部署到 GitHub Pages 或任意静态托管。

## 160 分拆解

| 科目 | 模块 | 目标分 |
|------|------|--------|
| 行测 | 资料分析 | 19/20 |
| 行测 | 判断推理 | 32/35 |
| 行测 | 言语理解 | 36/40 |
| 行测 | 常识判断 | 14/20 |
| 行测 | 数量关系 | 9/15 |
| 申论 | 小题（4道） | 57/80 |
| 申论 | 大作文 | 28/40 |
| **合计** | | **160/200** |

## 数据存储

学习进度和模考成绩保存在浏览器 `localStorage`，无需后端，隐私安全。

## 技术栈

React + TypeScript + Vite
